# ChainGrade 实验报告上游 LaTeX 模板对齐设计

## 1. 修复目标

最终实验报告应以 `Keldos-Li/typora-latex-theme` v0.3.3 的视觉与封面模板为主，而不是在其 CSS 上重新设计一套项目视觉系统。允许的修改只包括替换项目资料、本地化依赖资源，以及解决现有手写章节编号与上游自动编号的兼容问题。

## 2. 上游模板基线

上游 `resources/cover-template.md` 的封面顺序为：浙江大学校名 SVG、浙江大学校徽 SVG、论文标题、论文类型和课程信息表。封面主要依靠内联样式，使用方正公文仿宋、华文仿宋与华文黑体；正文、标题、表格、代码和打印页边距则由上游 `latex.css` 负责。

## 4. 资源与兼容策略

- `ZJU-name.svg` 与 `ZJU-logo.svg` 使用上游模板所引用的同一资源，并保存在项目 `typora-latex-theme/assets/`，避免 PDF 导出依赖 GitHub 网络连接。
- `chaingrade-latex.css` 只导入未经修改的 `latex-upstream.css`，不再覆盖正文、标题、表格、图片尺寸或自定义封面布局。
- 原报告标题已经写入“1、1.1”等编号，因此兼容层只关闭正文和目录伪元素的自动编号，防止出现“1  1.”。
- 删除目录后的空分页 `<div>`，改由打印模式中第一个 H2 标题触发分页，避免目录结束位置恰好跨页时产生整张空白页。

## 5. 验收标准

1. 封面 DOM 顺序与上游模板一致，并同时出现本地校名、校徽资源。
2. 学号准确显示为 `3240101782`。
3. 从正文第一章开始与原实验报告逐字一致。
4. 不再存在第 24 阶段的 `cover-school`、`cover-rule` 等自定义封面元素。
5. 目录和正文不产生双重编号。
6. 目录后不再由空元素额外生成一页。
7. Typora 用户主题目录中的入口 CSS 与项目文件哈希一致。
