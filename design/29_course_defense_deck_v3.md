# 课程答辩 PPT V3 设计说明

## 1. 设计目标

本次重制不改变 ChainGrade 的业务边界，也不形成课程版与竞赛版两个项目。PPT 需要在 20–30 页内讲清楚三件事：为什么成绩场景需要区块链；项目如何在同一主线上逐阶段演进；已经完成的结论分别由什么代码、数据和验收记录支撑。

课程大作业关注“成绩存证与查询”的完整工程闭环，竞赛关注创新应用、隐私、互操作、性能与韧性。PPT 因此把两类要求解释为同一项目的两套评价坐标：课程阶段保证功能完整，竞赛延展推动能力加深。

## 2. 叙事结构

全稿 26 页，按四段组织：

1. 第 1–7 页：目录、问题、四条原则、总体架构与七阶段地图。
2. 第 8–20 页：按“上一阶段缺点—本阶段设计—实现结果—遗留缺口”讲解存证、角色、隐私、修订、UI、工程恢复和标准 VC；关键约束配合代码展示。
3. 第 21–24 页：公开基准方法、吞吐与 P95、故障恢复、自动测试与三人贡献。
4. 第 25–26 页：区分已完成能力、当前限制和下一阶段，并回收总论点。

这种结构避免把 Fabric、私有集合、VC 等术语并列堆砌。每个技术选择前面都有问题，后面都有可观测结果；每个阶段的缺点自然成为下一阶段的输入。

## 3. 视觉形式

- 采用 16:9 编辑式版面，以可信蓝为主色，珊瑚色标记风险与限制，青绿色标记完成结果。
- 标题使用 Georgia 与宋体，正文使用 Segoe UI 与微软雅黑；大标题形成稳定的视觉锚点。
- 架构、状态机、流程和指标均用可编辑矢量元素表达；产品能力使用真实 UI 截图。
- 封面、迭代、隐私转折、VC 与结尾插图采用研究手帐式视觉，承担叙事转场，不替代真实证据。
- 结论页的研究手帐插图同时作为 26 页统一背景母题：封面直接使用原图，内容页以低透明度铺底并由白色卡片保证可读性，结论页提高背景权重以完成视觉回收。
- 代码页只保留影响可信边界的核心逻辑，包括公开/私有分离、状态守卫、主体绑定、修订原子性和 VC 验证链。

## 4. 数据口径

PPT 只采用仓库已经验收的数据：120 项项目测试、25 个链码方法、28 条 HTTP 路由、7 项基准工具、84 个合法负载单元；公开验证和私有查询的 C20 吞吐/P95、批量 50 条结果，以及 Peer、CCaaS、Orderer 三类恢复时间。单 Orderer 明确表述为“可恢复但非高可用”。贡献按魏子安 4、强璞 3、阳震 3 展示。

## 5. 交付形式

最终文件为 deliverables/course/ChainGrade_课程答辩_重制版.pptx，共 26 页；同名重制版讲稿 Markdown 与 26 页 PPT 备注一一对应。旧 9 页文件仅作为历史版本保留。
