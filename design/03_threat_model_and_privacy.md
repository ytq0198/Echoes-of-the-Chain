# 威胁模型与隐私设计 v0.1

日期：2026-08-25

## 1. 保护资产

- 学生身份、学号、成绩、排名、课程组合和申诉证据。
- 教师、复核员与管理员的私钥及身份属性。
- 凭证状态、版本关系、授权令牌和验证记录。
- Fabric 节点、状态数据库、链下数据库和对象存储中的数据。

## 2. 信任边界

1. 浏览器与 API 之间：不信任输入，必须鉴权、校验和限流。
2. API 与 Fabric Gateway 之间：使用组织身份和最小权限连接配置。
3. Fabric 组织之间：共同维护公开事实，但不默认共享私有成绩。
4. 私有集合与公共账本之间：公共账本只保存承诺、状态和必要索引。
5. 学生与外部验证者之间：披露必须由学生显式授权，验证者可能恶意保存或转发结果。

## 3. 主要威胁与控制

| 威胁             | 影响             | 第一阶段控制                                       | 同一项目的后续增强      |
| ---------------- | ---------------- | -------------------------------------------------- | ----------------------- |
| 伪造签发者       | 假成绩被接受     | Fabric MSP、可信组织注册、链码角色属性             | DID/VC 信任注册表       |
| 教师单独篡改成绩 | 内部越权         | 提交人与复核人分离、背书策略、不可覆盖版本         | 多组织/状态级背书       |
| 公共账本泄漏成绩 | 永久隐私损害     | 明文进入私有集合或链下密文，公开仅留哈希           | 不可链接选择性披露      |
| 字典攻击哈希     | 从低熵成绩猜明文 | 随机盐、结构化承诺、密钥化伪随机标识               | BBS+/匿名凭证           |
| 分享链接泄漏     | 未授权核验       | 128 位以上随机令牌、仅存哈希、过期、限次、绑定用途 | 绑定验证者 DID 与挑战值 |
| 重放验证         | 授权被重复消费   | 原子计数、nonce、短有效期、审计回执                | 不可链接一次性证明      |
| 撤销后仍被接受   | 使用过期成绩     | 每次在线查询链上状态，不仅验证旧签名               | 标准状态列表与缓存策略  |
| 管理员覆盖历史   | 审计失真         | 禁止更新原记录；修订新建版本并链接旧版             | 外部审计组织共同背书    |
| 申诉证据泄漏     | 学生隐私损害     | 正文/附件不上公共链、访问控制、内容哈希            | 客户端加密与按案授权    |
| 日志泄漏         | 二次暴露         | 结构化日志白名单、令牌/成绩脱敏                    | 自动隐私回归测试        |
| 恶意 CSV/输入    | 注入或资源耗尽   | Schema 校验、大小/行数限制、公式注入防护           | 模糊测试                |

## 4. 链上/链下数据边界

### 公共账本允许字段

- 随机凭证 ID
- 加盐学生伪标识
- 课程标识哈希
- 私有详情承诺
- 签发组织 MSP ID
- 模式版本
- 状态、版本、前序凭证 ID
- 交易时间、提交人与复核人身份摘要
- 撤销/申诉原因摘要哈希

### 公共账本禁止字段

- 姓名、学号、身份证明
- 精确成绩、排名、GPA、课程名组合
- 申诉正文、聊天、证据文件或下载地址
- 分享令牌、盐、私钥、连接凭据

### 私有集合/链下受控数据

- 成绩构成与最终成绩
- 学生标识映射和承诺盐
- 申诉正文与证据元数据
- 披露策略、授权次数和验证回执

链下文件使用内容哈希与链上事件关联；后续加入对象级加密和保留周期。

## 5. 隐私能力的准确表述

- Fabric 私有数据集合保护的是联盟成员之间的数据可见性。
- 加盐 Merkle 披露让验证方只看到被打开的字段，但相同根仍可能造成关联。
- BBS+ 可提供选择性披露和派生证明不可链接性，但不天然提供数值范围证明。
- “GPA 大于阈值且不泄漏 GPA”需要额外谓词证明机制，必须通过独立测试后才能作为已实现能力宣传。
- 验证方一旦看到披露值，技术上无法阻止其截图或另行保存；平台通过最小披露、用途绑定和审计降低风险，而非宣称绝对控制。

## 6. 安全测试清单

- 越权角色调用所有写交易。
- 提交人尝试自审。
- 私有载荷哈希不一致。
- 对已撤销/已取代凭证再次修订或申诉。
- 重复凭证 ID、重复申诉 ID和非法状态转换。
- 令牌重放、并发最后一次消费、过期与撤销。
- 公开账本、API 日志和错误响应的敏感字段扫描。
- peer 无权组织读取私有集合的负面测试。
