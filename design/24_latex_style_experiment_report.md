# ChainGrade 实验报告 LaTeX 风格化设计

> 状态：已被 `design/25_upstream_latex_template_alignment.md` 取代。第 24 阶段的自定义封面与视觉覆盖并非最终采用方案，保留本文只用于记录设计演变。

## 1. 目标与边界

本阶段只改变最终实验报告的呈现形式，不改写已经验收的实验事实。原文件 `deliverables/course/ChainGrade_最终实验报告.md` 保持不变，新增 `ChainGrade_最终实验报告_LaTeX风格.md` 作为可选交付版。

用户指定的 `Keldos-Li/typora-latex-theme` 实际上是 Typora CSS 主题，不是可执行的 Codex skill，也不会把 Markdown 编译成真正的 `.tex`。本阶段直接采用其官方 v0.3.3 Windows 发布包，使 Markdown 在 Typora 编辑和 PDF 导出时呈现接近中文 LaTeX 课程论文的版式。

## 2. 为什么采用“上游主题 + 项目覆盖层”

如果直接改写上游 `latex.css`，后续无法区分哪些规则来自第三方，版本升级也容易覆盖项目封面。因此交付物拆为两层：

| 层次 | 文件 | 职责 |
| --- | --- | --- |
| 上游基础 | `latex-upstream.css` | 字体体系、标题层级、表格、代码、公式、打印页边距等通用论文样式 |
| 项目覆盖 | `chaingrade-latex.css` | ChainGrade 封面、10.5pt 中文正文、A4 打印、图片尺寸、分页与编号兼容 |

覆盖层通过 CSS `@import` 引入上游文件。上游 GPL-3.0 许可证原样保存在同一目录，来源、版本和修改边界可追溯。

## 3. 内容结构调整

LaTeX 风格版在正文前增加三部分：

1. 浙江大学课程大作业封面，只填写已有的项目名、仓库、成员、专业和日期，不虚构教师、学号或贡献比例。
2. 中文摘要和关键词。摘要用实测数字说明系统做了什么、为何这样设计、结果能证明什么以及不能证明什么。
3. 自动目录，便于 Typora 导出 PDF 后定位章节。

从“1. 团队负责内容与最终结果”开始的正文与原报告逐字一致。原报告已经手工编号，项目覆盖层关闭上游标题计数器，避免出现重复章节号。

## 4. 视觉规则

- A4 页面，正文 10.5pt，中文优先使用思源宋体/华文宋体/宋体，西文优先使用 Latin Modern Roman。
- 封面使用黑白、高留白、细横线和衬线大标题，不加入开发阶段、竞赛提示词或制作痕迹。
- H1 居中，H2 使用细底线建立章节边界，H3 保持紧凑；正文两端对齐。
- 表格统一全宽、9pt，表头浅灰；图片居中，限制最大高度，尽量避免打印跨页。
- 封面和前置摘要/目录各自分页，表格、代码块和图片尽量整块打印。

## 5. 验收标准

1. 原报告文件未被覆盖。
2. 两版报告从正文第一章开始完全一致。
3. 7 个图片引用全部存在。
4. Markdown 可生成包含封面、2 个 H1、17 个 H2、34 个 H3、14 个表格、7 张图片和 51 个目录链接的 HTML 结构。
5. 上游 CSS、覆盖层、许可证和使用说明齐全。
6. 在安装 Typora 的环境选择 `chaingrade-latex` 后，人工检查封面、摘要、目录、表格和图片分页，再导出最终 PDF。
