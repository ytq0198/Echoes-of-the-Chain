## 2. 迭代节奏

### Iteration 0：架构与技术尖峰

- 冻结需求、权限、威胁模型和数据边界。
- 建立 monorepo、共享 Schema 和链码核心测试。
- 在服务器启动 Fabric 最小网络并完成一笔真实交易。

退出标准：链码状态机单测通过；真实网络可部署；提交人不能自审。

### Iteration 1：签发闭环

- 教师录入/导入、复核、学生查询、公开状态验证。
- API 与 Fabric Gateway 联通；基础角色登录。

退出标准：从录入到公开验证的 E2E 自动化通过。

### Iteration 2：隐私与修订申诉

- 私有数据集合、成绩修订、撤销、申诉、字段披露和授权令牌。
- 加入隐私负面测试和结构化审计事件。

退出标准：无权组织无法读取明文；过期/撤销/重放均被拒绝。

### Iteration 3：产品完成度

- 完善视觉、CSV、二维码、看板、空状态、异常恢复和演示数据。
- 编写部署文档、用户手册、课程报告、PPT 和视频脚本。

退出标准：全新环境一键部署；7 分钟课程演示可稳定完成。

### Iteration 4：面向竞赛的连续深化

- BBS+/匿名凭证和阈值证明技术尖峰。
- 跨机构验证/互认、Caliper 性能实验、安全攻击实验。
- 生成严格匿名的设计与测试报告。

Iteration 4 继续使用前述同一产品、仓库、数据模型和部署体系，只是在已有成果上增加能力；课程答辩和竞赛提交不是两个项目。

## 3. 协作规则

- `main` 始终可运行，功能使用短分支和 Pull Request。
- 每个 PR 包含测试、文档更新和可复现验证命令。
- 领域/接口变更必须先更新 `design/`；实验结果同步到 `reports/`。
- 不提交密钥、真实隐私数据和运行生成证书。
- 不以提交行数衡量最终贡献；贡献评分结合设计、实现、测试、文档、演示和问题解决。
