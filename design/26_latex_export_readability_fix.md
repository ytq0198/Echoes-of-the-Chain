# 阶段 26：LaTeX 风格报告导出一致性与可读性修复

## 1. 问题与边界

本阶段不重写实验报告，也不重新设计一套视觉风格。排版继续以 `Keldos-Li/typora-latex-theme` v0.3.3 为基础，只修复上游主题在当前 Windows、Typora 和 20 余页工程报告组合下暴露出的兼容问题：字体回退、屏幕与打印宽度不同、目录过长、超长浏览器截图跨页以及目录后的空页。

## 2. 原因判断

旧 PDF 共 22 页。字体资源显示英文正文实际使用 Times New Roman，说明虽然 Windows 已安装 Latin Modern，Typora 内置 Chromium 仍未正确解析主题声明的字体族别名。上游正文为 9.5pt，在 A4 页面上显得偏细偏小。`#write` 的 21cm 宽度与左右内边距按 content-box 计算，导致屏幕编辑宽度大于打印正文宽度，换行位置不一致。目录收录二、三级标题，占两页且第二页内容很少。1264×3036 的纵向截图若保持原始宽高比，会被浏览器分页算法推迟或拆分，形成稀疏页面。

## 3. 最小修复设计

1. 保留上游 CSS 作为排版主体，自定义入口只覆盖必要变量和打印兼容规则。
2. 正文从 9.5pt 调整为 10.5pt，改善投影与纸面阅读；不改变标题层级和正文内容。
3. 用 `@font-face` 按 `LMRoman10-Regular/Bold/Italic/BoldItalic` 与 `LMMono10-Regular` 的 PostScript 名绑定本机 Latin Modern，避免字体族别名解析失败后回退到 Times New Roman。
4. `#write` 使用 `box-sizing: border-box`，使屏幕 A4 框和打印版正文宽度均约为 17cm。
5. 目录仅显示章级标题。正文原有章节编号保留，关闭上游自动编号，避免双重编号。
6. 普通图片最大高度限制为 18.5cm并保持比例；封面校名、校徽单独取消高度限制。
7. 第一章标题负责开始新页，不再叠加额外分页元素。

## 4. 验收标准

- 封面继续使用上游浙江大学模板结构和本地校名、校徽 SVG。
- PDF 为 A4，目录单页，正文从新页开始，无完整空白页。
- 英文正文字形不再以 Times New Roman 资源出现；中文仍使用系统可用的宋体回退链。
- 长截图不被拆成两页，图片和表格无裁切、遮挡或越过页边距。
- 报告正文、测试数字、交易 ID、哈希和结论不被本阶段修改。
