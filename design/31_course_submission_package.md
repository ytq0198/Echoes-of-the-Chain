# 课程最终提交包设计

## 1. 目标

本阶段把同一 ChainGrade 项目的代码、答辩材料、实验报告、项目介绍、演示视频和成员分工整理为一个可直接提交的目录。课程原始要求是清单依据；历史材料中“课程不要求视频”的判断已经更正。

## 2. 目录原则

最终包按用途分为源码、答辩材料、项目文档、演示视频、成员分工和设计实验过程六部分。运行环境、依赖缓存、私有密钥、日志、Git 历史和中间构建工程不进入压缩包。这样既保留复现材料，也避免泄露服务器凭据或用历史版本干扰评分。

## 4. 打包与验证

源码从 Git 跟踪文件中抽取，避免混入 `node_modules`、`.runtime` 和密钥。演示视频保持原始文件，不重新编码。压缩完成后检查目录清单、成员信息、PPT 页数、PDF 页数、视频 MP4 结构以及 SHA-256；最后从压缩包列出内容，确认不存在私有环境文件。

课程尚未提供组号，因此包名暂用“组号待填”。获得组号后只需重命名压缩包，不需要改变包内内容。
