## 3. 快速运行

推荐在 Ubuntu 22.04 环境运行。先安装 Node.js 24、pnpm 11 和 Hyperledger Fabric 2.5.16，再进入 `01_项目源代码` 执行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm check
corepack pnpm test
```

真实 Fabric 的完整启动、端口和身份配置见 `03_项目文档/ChainGrade_虚拟机开发环境与适配说明.md`。演示服务器的短期账号为 `demo-issuer`、`demo-reviewer` 和 `demo-student`；密码只保存在部署端私有环境文件中，不进入提交包。

## 4. 材料口径

- 项目在同一仓库内完成课程基础功能和后续竞赛化完善，没有拆分为两套系统。
- 最终实验报告中的性能结论来自单机回环网络，不能外推为生产容量。
- 有限披露属于字段级授权，不声称实现 BBS+ 或零知识证明。
- 当前单 Orderer 能恢复，但不具备写入高可用。

## 5. 提交提示

课程要求三名成员各自提交最终文件。当前压缩包以组长身份整理；组员提交时应复制同一压缩包，并按“组号-组长或组员-姓名-项目名称”的课程规则改名。由于尚未提供课程组号，现有包名使用“组号待填”占位符。

真实 Fabric 网络、API 和 Web 的启动方式见 `03_项目文档/ChainGrade_虚拟机开发环境与适配说明.md`。演示前按照 `04_演示视频/ChainGrade_课程演示录屏脚本.md` 的预检部分检查账本和服务状态。

## 4. 登录角色

演示环境包含 `demo-issuer`、`demo-reviewer` 和 `demo-student` 三个独立账号。密码从部署机器的 `.runtime/private/preview.env` 读取，不写入提交包。公开验真页面无需登录。

## 5. 安全说明

提交包不包含 `.git`、`node_modules`、`.runtime`、密钥、私有环境文件和服务日志。源码中的 `.env.example` 仅提供变量名和示例值，不包含演示环境密码。

课程要求三名成员分别提交最终文件。当前包名中的“组号待填”必须在上传前替换为课程公布的实际组号；组员可复制同一压缩包，并按“组号-组长或组员-姓名-ChainGrade”格式重命名。
