# ChainGrade 课程演示录屏脚本

建议总时长 6–7 分钟，录制 1920×1080、30 fps，浏览器缩放保持 100%。录制前按 `deliverables/demo/runbook.md` 完成服务器预检和 SSH 隧道，关闭通知、密码管理器弹窗及无关窗口。视频只展示真实 Fabric 路径，不混入离线模拟数据。

## 镜头与讲解

| 时间 | 画面与操作 | 要说清楚的结果 |
| --- | --- | --- |
| 0:00–0:30 | 首页与产品标题 | 项目解决成绩可核验与隐私暴露的冲突；课程和竞赛共用一个项目 |
| 0:30–1:15 | 教师登录，打开签发/批量导入 | 成绩明文经 transient 进入私有集合，公共账本只留承诺、状态和审计信息 |
| 1:15–2:00 | 复核员完成独立复核 | 发行与复核分权；凭证从 `PENDING_REVIEW` 变为 `ACTIVE` |
| 2:00–2:45 | 学生工作台查看本人成绩并提交申诉 | 学生属性约束读取私有成绩；申诉与成绩版本可追踪，不直接覆盖旧记录 |
| 2:45–3:30 | 教师处理修订，展示旧版 `SUPERSEDED` | 新版本链接旧版，状态机保证历史仍可审计 |
| 3:30–4:20 | 公开验真页输入凭证 ID，再展示二维码/有限披露 | 公开端只返回状态和匹配结论，不返回成绩明文；有限披露有用途、验证者、期限和次数约束 |
| 4:20–5:10 | 学生导出标准 VC JSON，公开页上传验证 | Ed25519 签名、链上状态和详情锚定三层验证；可现场篡改一个字段展示失败 |
| 5:10–5:50 | 展示性能报告表格或答辩 PPT 证据页 | 120 项项目测试与 7 项基准测试通过；84 个正式负载单元合法请求失败 0；C20 公开验真中位 746.614 req/s、P95 38.202 ms |
| 5:50–6:20 | 展示故障恢复与双 Peer 账本证据 | 稳态恢复 14.030–22.482 秒；当前单 orderer，因此只称恢复能力，不称高可用 |
| 6:20–6:50 | 回到总工作台或结论页 | 已完成 Fabric 闭环、修订/申诉、有限披露、标准 VC 与可靠性证据；未来工作是 BBS+/零知识阈值证明、三 orderer 和真实教务接入 |

## 录制前检查

```bash
./infra/demo/preview.sh check
./infra/demo/preview.sh start
./infra/demo/preview.sh status
```

Windows 本机保持 SSH 隧道：

```powershell
ssh -N -p 9961 -L 5173:127.0.0.1:5173 weizian@10.98.36.128
```

## 录制后检查

- 从头到尾完整观看一次，确认画面、声音、鼠标位置和隐私信息无误。
- 检查视频中没有口令、私钥、学生真实数据、终端历史或个人通知。
- 核对口播数字与最终报告一致，不把计划能力说成已完成。
- 将视频放入最终提交包，不要把大体积视频提交进 Git 仓库。
