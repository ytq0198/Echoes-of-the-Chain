# 匿名函评材料工作区

这里承载同一 ChainGrade 项目的竞赛材料，不承载另一套代码或产品。所有文本、图片、导出文件与压缩包必须保持匿名；不得加入参赛单位、指导人员、作者身份、个人邮箱、个人仓库地址或可反向识别身份的水印。

计划交付：

- `设计报告+ChainGrade.pdf`：应用背景、问题、思路与方案、功能与指标、软件流程。
- `测试报告+ChainGrade.pdf`：测试平台、合成数据、功能/安全/性能结果与分析。
- `其他文件+ChainGrade.zip`：可执行源代码、部署说明、匿名演示视频及必要依赖清单。

提交前执行仓库文本扫描，并对最终 PDF 属性、图片元数据、视频属性、压缩包清单和源码注释再做人工复核。所有功能结论从 `deliverables/common/evidence-index.md` 取证；未完成能力只进入未来工作。
