# ChainGrade 测试报告骨架

## 1. 测试目标与范围

验证核心业务完整性、链上真实性、隐私与权限边界、异常原子性、可恢复性、浏览器适配和性能基线。

## 2. 测试平台

记录匿名化的 CPU/GPU/内存、操作系统、Node.js、Fabric、浏览器及网络拓扑版本；不记录主机名、账户名或绝对个人目录。

## 3. 测试数据

只使用合成学生、课程、成绩、盐值和申诉文本；说明规模、分布和生成方法，不使用真实教务数据。

## 4. 功能与状态机测试

覆盖单条/批量签发、复核、驳回、撤销、修订、申诉、公开验真、本人查询和有限披露，并列出非法转换负向用例。

## 5. 安全与隐私测试

覆盖未登录、角色越权、非本人访问、CSRF/来源、过期或超次授权、错误验证者、哈希不一致和敏感信息扫描。

## 6. Fabric 与恢复测试

记录链码定义、双 Peer 高度/哈希、真实 transaction ID 取证方法、无损重启、冷备份 SHA-256 和恢复一致性。

## 7. 性能与稳定性测试

后续用固定数据规模报告吞吐、P50/P95/P99 延迟、失败率、资源占用和多轮方差；当前没有数据时不得预填结论。

## 8. 浏览器与视觉验收

记录桌面/移动视口、关键状态截图、横向溢出、控制台 warning/error 和键盘/对比度检查。

## 9. 结果分析与局限

把观察事实、原因推断和改进计划分开；单 orderer、受控身份和 bearer capability 均需列为边界。
