# Iteration 0 阶段报告：统一产品架构与链码垂直切片

日期：2026-08-25

## 1. 阶段目标

将已选方向转化为可执行产品规格和工程骨架，以自动测试验证成绩签发、修订和申诉的核心安全不变量。

## 2. 统一项目原则

课程答辩和 CCF 竞赛使用同一个 ChainGrade 项目。项目只维护一个仓库、一个领域模型和一条连续迭代主线。课程提交与竞赛提交可能因时间、篇幅和匿名规则生成不同材料，但不建立两套产品或长期代码分支。

## 3. 已完成设计

- 产品问题、角色、权限、用户故事和验收条件。
- 公共账本、隐式私有集合和链下存储的数据边界。
- 威胁模型、隐私能力边界和安全负面测试清单。
- 三组织 Fabric 拓扑、凭证状态机和申诉状态机。
- 三人主责、交叉评审规则和连续迭代计划。

## 4. 已完成实现

### 工程骨架

- pnpm TypeScript monorepo。
- Vue 3 响应式 Web 首页。
- Fastify API 健康检查与能力元数据接口。
- Zod 公共输入 Schema 和领域类型。
- Hyperledger Fabric TypeScript 链码。

### 链码交易

- `CreateCredentialDraft`
- `CreateAmendmentDraft`
- `ApproveCredential`
- `RejectCredential`
- `RevokeCredential`
- `ReadCredential`
- `VerifyCredential`
- `SubmitAppeal`
- `ReviewAppeal`
- `ReadAppeal`

### 已建立的安全不变量

1. 成绩详情哈希与公共承诺不一致时拒绝交易。
2. 成绩提交身份不能复核自己的草稿。
3. 复核员必须属于原签发组织。
4. 修订不能改变学生或课程身份。
5. 新修订通过时，旧版本在同一交易中变为 `SUPERSEDED`。
6. 只有有效凭证可以申诉或撤销。
7. 只有凭证对应学生且属于签发组织才能申诉。
8. 成绩和申诉详情进入 `_implicit_org_<MSPID>` 隐式私有集合，不进入公共状态。

## 5. 验证结果

- TypeScript 全工作区类型检查通过。
- 共享 Schema 测试通过。
- 链码状态机与负面安全测试 12 项通过；语句/行覆盖率 91.47%，函数覆盖率 100%，达到当前不低于 85% 的目标。
- API 注入测试通过。
- 所有工作区生产构建通过。
- Web 桌面端与 390px 移动端真实浏览器渲染通过，无控制台错误和横向溢出。
- 移除不必要的完整 UI 组件库后，首页 JavaScript 产物由约 981 KB 降至约 63 KB（均为未压缩构建报告值）。
- 学校服务器在项目 `.tools/` 内使用 Node 24.19.0 与 pnpm 11.19.0 复跑类型检查、16 项工作区测试、链码覆盖率门槛和生产构建，结果全部通过；服务器工作树保持干净。
- 服务器当时无法直连 GitHub 443 端口，改用本机生成 Git bundle、经 SSH 传入服务器项目 `.git` 后执行 `--ff-only` 快进同步；未覆盖服务器文件，也未修改允许目录以外的项目。

## 6. 尚未完成及诚实边界

- 当前链码测试使用模拟 Fabric Context，尚未完成真实 peer 的部署交易。
- 当前 API 尚未接入 Fabric Gateway 和 PostgreSQL。
- 当前 Web 是视觉与信息架构骨架，按钮尚未连接业务流程。
- 尚未实现外部披露令牌、Merkle 字段证明、BBS+ 或阈值证明。
- 因此当前成果是可测试技术尖峰，不应描述为完整可用产品。
