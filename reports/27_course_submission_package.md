# 阶段 27 实验进程：课程最终材料与压缩包

## 1. 本阶段结果

本阶段依据课程原始 PDF 重新核对提交要求，将演示视频恢复为必交项，并统一三名成员的姓名、学号和 4:3:3 贡献口径。最终材料覆盖源码、25 页答辩 PPT、实验报告、项目介绍、演示录屏、分工说明、README、环境说明及阶段设计和实验记录。

## 2. 设计原因

历史交付目录同时保留多个 PPT 和 PDF 版本，容易让提交者误选。运行目录还包含依赖缓存、密钥和服务日志，不能直接把仓库文件夹整体压缩。因此本阶段只选择明确的最终版本，并从 Git 跟踪文件中抽取源码。视频保持用户录制的原始 MP4，避免二次编码降低界面文字清晰度。

## 4. 验收方法

1. 文本扫描确认三组“姓名—学号”映射没有互换。
2. PPT 从已确认的 SVG 工程重新导出，25 张幻灯片和 25 份 Speaker Notes 一一对应。
3. 实验报告通过 Chrome 重新导出并逐页渲染检查，封面和团队表均显示三名成员学号。
4. 项目介绍 DOCX 沿用原表格结构补充学号，避免大幅改变 16 页版式。当前运行环境缺少捆绑 LibreOffice，因此仅完成 OOXML 结构与文本回读校验，不把它表述为新的逐页渲染验收。
5. 压缩包排除 `.git`、`node_modules`、`.runtime`、`.tools`、私有环境文件、密钥、日志和历史构建工程。

## 5. 证据边界

课程组号尚未提供，包名只能使用“组号待填”占位符。用户录制视频的内容属于真实操作证据，但本阶段不改变其画面和声音，也不将视频质量主观评价写成实验结论。
