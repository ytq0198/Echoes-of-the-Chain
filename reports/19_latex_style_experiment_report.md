## 1. 本阶段完成内容

本阶段将最终 Markdown 实验报告制作成 Typora 可直接应用的 LaTeX 视觉版，同时保留原报告作为事实基线。新增内容包括论文式封面、中文摘要、关键词、自动目录、上游主题 CSS、ChainGrade 覆盖层、GPL-3.0 许可证和使用说明。

排版来源为 `Keldos-Li/typora-latex-theme` 官方 v0.3.3 Windows 发布包。没有把该仓库误当作会生成 `.tex` 的编译工具；最终文件仍是 Markdown，所谓“LaTeX 风格”指其在 Typora 和 PDF 导出中的视觉呈现。

## 2. 关键设计原因

原报告已经包含完整的数据、原因分析、失败记录和证据边界，因此本阶段没有为了“像论文”而删减实验过程，也没有添加未完成的零知识证明或性能数据。摘要选取 25 个链码方法、25 条 HTTP 路由、52/52 自动测试、85.91% 语句覆盖率、双 Peer 高度 12、批量冲突后 404 和 12.50 秒冷彩排等结果，用数字说明实际完成程度。

主题采用两层 CSS。上游文件保持原样，项目覆盖层只负责 ChainGrade 封面、字号、分页和手工章节编号兼容。这使第三方来源与项目修改清晰分离，也避免上游自动计数器与报告已有的“1、1.1”编号叠加。
